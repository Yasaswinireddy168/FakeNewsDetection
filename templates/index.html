How TruthLens Works

TruthLens uses Natural Language Processing and Machine Learning to analyze news articles. The text is cleaned during preprocessing and converted into numerical features using TF-IDF. Multiple machine learning algorithms are trained and evaluated before selecting a model for prediction.
